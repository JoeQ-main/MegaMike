# MegaMike

MegaMike is a browser emulation of a classic 1970s monophonic analog synthesizer:
the panel, the three-oscillator voice, the transistor-ladder filter, the two
contours, the wheels and the 44-key keyboard. No build step and no runtime dependencies; the sound is generated by
custom DSP running in a Web Audio `AudioWorklet`.

## Running

**Windows:** download `MegaMike.exe` from the
[Releases page](https://github.com/JoeQ-main/MegaMike/releases/latest) and
double-click it. It opens the instrument in its own window using the Edge
WebView2 runtime that ships with Windows 10 and 11. (The exe is not checked
into the repository; see "Rebuilding the executable" below to build it yourself.)

**Any browser:** the page must be served over http (AudioWorklet modules do
not load from `file://`). Double-click `MegaMike.bat`, or run

```bash
python -m http.server 8766
```

and open <http://localhost:8766/>. Click anywhere to power up the audio.

## Playing

- **Mouse / touch**: click and drag across the keys (glissando works). Drag knobs
  up and down, hold Shift for fine control, scroll over them, double-click to
  reset. Click a range or waveform selector to step it, or drag it. Drag the
  wheels; the pitch wheel springs back.
- **Computer keyboard**: `Z S X D C V G B H N J M , L . ; /` from C3 and
  `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` from C4. `[` and `]` shift octaves,
  `Esc` is all notes off.
- **MIDI**: any connected input (Chrome and Edge). CC1 drives the mod wheel and
  pitch bend drives the pitch wheel.
- **Presets**: the toolbar has factory patches plus Save / Delete (stored in the
  browser) and Export / Import as JSON.
- **Sequencer**: the module to the right of the synth plays eight steps, each an
  eighth note at the Tempo knob's rate. Every step has a pitch knob (semitones
  above the root, shown as a note name) and a rocker that turns it into a rest;
  Gate sets how long each note is held. Flip Run to start. While it runs, any key
  you press becomes the root of the sequence. The pattern is remembered in the
  browser.

## What is emulated

| Section | Behaviour |
| --- | --- |
| Keyboard | Monophonic, lowest-note priority, single trigger (contours restart only when no key was held), glide with on/off switch. |
| Oscillators | Three oscillators, ranges LO / 32' / 16' / 8' / 4' / 2', six waveforms (triangle, triangle-saw, saw, square, wide and narrow rectangle), band-limited with PolyBLEP. Osc 3 can be freed from the keyboard to act as the LFO. |
| Mixer | Five channels with on/off rockers. External Input feeds the main output back into the mixer for the classic overdrive; the lamp shows overload. White or pink noise. |
| Filter | 24 dB/oct four-pole ladder (Huovilainen model, 2x oversampled) with keyboard tracking 1/3 and 2/3, contour amount, modulation and self-oscillation at high emphasis. |
| Contours | Attack, decay, sustain for filter and loudness; the Decay rocker gives a release equal to the decay time. |
| Controllers | Tune, glide, modulation mix (osc 3 against noise), osc and filter modulation switches, pitch and mod wheels, A-440 reference. |
| Sequencer | Eight-step analog-style sequencer with tempo, gate, rests and keyboard transpose. Events are timestamped on the audio clock and applied sample-accurately inside the worklet. |

## Rebuilding the executable

```bash
pip install pywebview pyinstaller
build.bat
```

This generates the icon, runs PyInstaller and copies the result to
`MegaMike.exe`. Intermediate files go under `build/`.

## Tests

The DSP is plain JavaScript with no browser globals, so it runs under Node:

```bash
npm test
```

## Files

| File | Purpose |
| --- | --- |
| `index.html`, `style.css` | Panel layout and look |
| `src/params.js` | Every control: id, label, range, default |
| `src/widgets.js` | Knob, rotary selector, rocker switch and wheel widgets |
| `src/panel.js` | Builds the panel, wires widgets, presets, keyboard and MIDI to the engine |
| `src/keyboard.js` | On-screen keys, computer keyboard and MIDI input |
| `src/presets.js` | Factory patches and localStorage persistence |
| `src/sequencer.js`, `src/seqpanel.js` | Step sequencer logic (pure, tested) and its panel and scheduler |
| `src/engine.js` | AudioContext and worklet messaging |
| `src/worklet.js` | AudioWorklet processor hosting the voice |
| `src/dsp/` | Oscillator, noise, envelope, ladder filter and voice |
| `tests/` | Node unit tests for the DSP |
| `launcher.py`, `build.bat`, `tools/make_icon.py` | Native Windows launcher and build |
| `docs/superpowers/specs/` | Design notes |
